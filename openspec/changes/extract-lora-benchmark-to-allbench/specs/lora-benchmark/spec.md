# Spec Delta

## Purpose

为独立 AllBench 提供可追溯的 LoRA 图像模型评测契约，将数据版本、固定推理协议、参考图片和模型输出关联起来，分别报告能力指标与执行证据，避免将合成流程测试解释为真实模型收益。

## ADDED Requirements

### Requirement: 正式样本可替换的完整执行链

系统 SHALL 提供统一配置入口，串联参考样本校验、匹配底模/LoRA 对照生成、三个可用真实编码器、指标和可阅读报告；逐阶段保留身份和失败证据，配置替换后使用新目录，不能混用旧结果。

#### Scenario: 样本和适配器准备完成
- **WHEN** 用户配置本地匹配 LoRA、触发词、参考划分及提示，提供固定本地模型组件和三个编码器
- **THEN** 单一运行命令完成完整配对矩阵和 DINO/CLIP/VGG19 指标，输出 JSON、CSV、HTML 及覆盖缺口；中断只补未提交项，人工效果验收仍保持独立。

#### Scenario: 权重无法完整加载
- **WHEN** LoRA 格式不受支持、目标层不存在或张量未完整挂载
- **THEN** 在生成前失败，不将未生效的适配器输出标为成功对照。

### Requirement: 固定协议和输入完整性

系统 SHALL 固定底模、适配器、数据发布、训练预算、生成配置、提示及种子，并为图片与特征绑定摘要；不同协议或输入不能复用旧结果。

#### Scenario: 恢复时图片或协议变化
- **WHEN** 使用原结果目录重新评测且输入图片或配置已经变化
- **THEN** 拒绝恢复并说明身份不匹配，不静默使用历史分数。

### Requirement: 分层多指标评测

系统 SHALL 按概念和提示类型分别报告图像余弦相似度、平方质心距离、CLIP 文图相似度、逐提示 Vendi 和同提示同种子的 VGG19 Gram 风格差异，缺少编码器或有效样本时显式返回未测原因。

#### Scenario: 未提供风格特征
- **WHEN** 图像特征可用但 VGG19 特征缺失
- **THEN** 其他指标仍可计算，风格差异标记未测，不填零或宣称完整复现论文。

### Requirement: 对照覆盖和防泄漏

系统 SHALL 校验 base/adapted 的提示和种子配对、参考划分和图像重复，拒绝缺失、重复或未知成员，生成全量预期任务清单；训练参考和独立留出参考分别报告。

#### Scenario: 少交一个适配器输出
- **WHEN** 已冻结清单中的某个提示与种子缺少 adapted 图片
- **THEN** 完整评测校验失败，不能悄悄减少分母。

### Requirement: 流程证据与效果结论分离

系统 SHALL 显式标注合成数据、人工特征、真实预训练编码器和真实 LoRA 输出的验证层级，保存成功数量、缺失项与恢复记录，不依据合成测试形成模型排名或收益结论。

#### Scenario: 在 node94 上对合成图片执行预训练编码
- **WHEN** 预训练 DINOv2 成功计算全部合成图片特征并生成报告
- **THEN** 报告只能证明该编码器及评测流程运行成功，真实概念、CLIP/VGG 路径和 LoRA 效果按实际执行情况单独标记。

### Requirement: 真实生成与底模独立验收

系统 SHALL 支持固定本地 FLUX.2-klein-9B 权重和采样配置出图，记录逐项生成回执、组件及产物摘要，并支持恢复；未提供 LoRA 时使用明确 base_only 模式，不创建虚假 adapted 结果，缺少参考不计算保真结论。

#### Scenario: 只提供 FLUX.2-klein-9B 底模
- **WHEN** 用户执行 base_only 生成测试且未提供 LoRA 或概念参考图
- **THEN** 完成 base 提示/种子矩阵，真实生成和可用编码器评测可验收，LoRA 效果和参考保真标记未测。

#### Scenario: 生成中断后恢复
- **WHEN** 部分逐图回执已提交后生成进程中断
- **THEN** 重放相同输入只补缺失项，图片或权重变化时拒绝复用，已完成项不重复调用模型。
