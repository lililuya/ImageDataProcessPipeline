## 3. P2：水印裁剪与整图文字过滤

对应[水印规格](specs/imagecaption-watermark-crops/spec.md)和[文字区域规格](specs/imagecaption-text-region-filter/spec.md)。

- [x] 3.1 分离水印召回候选、确认策略及present/absent/unknown/失败状态，保存模型、坐标与证据引用；测试低置信候选不自动裁剪、空OCR不否定图形水印及旧策略兼容。
- [x] 3.2 实现同时约束边距、保留面积、短长边和允许区域的确定性裁剪搜索；以构造几何夹具验证最大面积方案失败但另一方案可行、多框相交、边缘及无可行方案等情况。
- [x] 3.3 连接实际裁剪执行与视图记录，在取整、方向和编码对齐后复核尺寸、比例、交集及输出摘要；使用合成图验证JPEG对齐和策略允许的格式回退，并验证原始输入不变。
- [x] 3.4 接入残余水印复检及裁后监督失效标记，保留无法合格裁剪的确认原图和不确定候选；测试残余水印不进入主集、待复核与辅助候选分开、旧caption不能自动绑定新视图。
- [x] 3.5 增加整图文字检测适配器及坐标标准化，识别结果与检测几何独立；用合成文字夹具验证无水印框仍执行文字检测，超时、不支持与正常无文字可区分。
- [x] 3.6 实现裁边后的区域并集面积和固定局部分组的最大文字块面积，冻结置信/面积/分组参数；验证重叠框只计一次、分散文字不吞并空白、异常全图框进入复核和未校准状态不假通过。
- [x] 3.7 接入原图及裁后文字门控、几何重投影或重检测依据，并上报相应阶段进度；构造裁后占比增大的样本验证主集阻断及原图/视图观测分别可追溯。
- [x] 3.8 编写候选确认、联合裁剪、文字门槛及校准操作说明，形成可填写的领域审核报告；验证配置回放和审核覆盖记录，不用几何夹具通过宣称真实误检率已下降。
