# Tasks

本change为ImageCaption产品实施清单，2026-10-22首版累计完成7/40项，证据见[首版实施记录](../../../docs/imagecaption-v0.2-status.md)。版本骨架和其他进度能力已有部分实现，未满足整项条件的任务继续保留未勾选。实施顺序为P0→P1→P2→P3→P4→P5，优先让现有CLI处理获得真实进度，再接入新质量能力。旧`design-image-data-framework`的21/70项不计入本清单；合成验证不代替真实质量校准。

## 2. P1：CLI终端进度与只读网页看板

对应[CLI进度规格](specs/imagecaption-cli-progress/spec.md)。本组使用现有处理阶段即可验收，不等待美学模型或新caption模型上线。

- [ ] 2.1 定义版本化阶段/子步骤事件与结果checkpoint契约，包含分母、单位、分片、尝试代次、源时间和序号；验证未知总量、零输入、图片/变体/文件/字节及并行节点的契约样例。
- [ ] 2.2 为CLI/direct执行器加入持久待发送队列及运行登记，事件引用已提交结果并可由checkpoint补建；通过提交后断电式终止、队列重放及离线运行测试验证结果不丢失、不提前计完成。
- [x] 2.3 实现幂等接收、有效尝试隔离和进度投影；验证重复/乱序事件、旧worker迟到、分片恢复及同工作结果复用后只计一次，且失效尝试无法覆盖当前结果。
- [ ] 2.4 实现互斥主结果聚合及阶段验收状态，分别记录通过、分流、复核、最终失败、运行、重试等待、待处理；测试计数恒等式、多原因不重复相加、重新打开阶段和处理100%但仍阻塞发布。
- [ ] 2.5 接入现有扫描、检测、OCR、prepare、caption与export的内部进度钩子，包含模型加载、分片执行、文件复制和校验；合成CLI集成运行应能观察长任务的子步骤及实际工作量，不能只看到0/1操作。
- [x] 2.6 增加CLI status/watch与结构化JSON输出，支持本地离线状态和服务端状态来源标识；验证关闭终端、重开watch、TTY/非TTY输出及远端中断后仍能读取最后可信进度。
- [x] 2.7 扩展现有查询API和React页面，默认显示运行列表、阶段卡片、并行活动节点、子步骤及分片详情；用浏览器集成测试验证CLI启动后可发现、刷新不触发执行、旧客户端字段兼容且无图片/语义内容泄露。
- [x] 2.8 实现心跳、最后有效进展、接收时间及同步过期判定，增加窗口速率和有条件ETA；用受控时钟验证冷启动、缓存跳增、暂停、复核、心跳存活但无进展及断线补报时的显示。
- [x] 2.9 增加有界游标/修订号查询和持久阶段历史，保留legacy_snapshot证据等级；通过大量合成事件验证分页、浏览器重连及每次刷新不全表/全目录扫描，历史记录不产生虚假实时速率。
- [x] 2.10 编写CLI看板使用与排错说明，提供脱敏的多阶段合成演示；实际演练断线恢复、失败定位及只读访问，明确处理百分比、阶段验收与版本可用的区别。

## 3. P2：水印裁剪与整图文字过滤

对应[水印规格](specs/imagecaption-watermark-crops/spec.md)和[文字区域规格](specs/imagecaption-text-region-filter/spec.md)。

- [ ] 3.1 分离水印召回候选、确认策略及present/absent/unknown/失败状态，保存模型、坐标与证据引用；测试低置信候选不自动裁剪、空OCR不否定图形水印及旧策略兼容。
- [ ] 3.2 实现同时约束边距、保留面积、短长边和允许区域的确定性裁剪搜索；以构造几何夹具验证最大面积方案失败但另一方案可行、多框相交、边缘及无可行方案等情况。
- [ ] 3.3 连接实际裁剪执行与视图记录，在取整、方向和编码对齐后复核尺寸、比例、交集及输出摘要；使用合成图验证JPEG对齐和策略允许的格式回退，并验证原始输入不变。
- [ ] 3.4 接入残余水印复检及裁后监督失效标记，保留无法合格裁剪的确认原图和不确定候选；测试残余水印不进入主集、待复核与辅助候选分开、旧caption不能自动绑定新视图。
- [ ] 3.5 增加整图文字检测适配器及坐标标准化，识别结果与检测几何独立；用合成文字夹具验证无水印框仍执行文字检测，超时、不支持与正常无文字可区分。
- [ ] 3.6 实现裁边后的区域并集面积和固定局部分组的最大文字块面积，冻结置信/面积/分组参数；验证重叠框只计一次、分散文字不吞并空白、异常全图框进入复核和未校准状态不假通过。
- [ ] 3.7 接入原图及裁后文字门控、几何重投影或重检测依据，并上报相应阶段进度；构造裁后占比增大的样本验证主集阻断及原图/视图观测分别可追溯。
- [ ] 3.8 编写候选确认、联合裁剪、文字门槛及校准操作说明，形成可填写的领域审核报告；验证配置回放和审核覆盖记录，不用几何夹具通过宣称真实误检率已下降。

## 4. P3：质量评分、分类与数据池

对应[质量分流规格](specs/imagecaption-quality-pools/spec.md)。

- [ ] 4.1 增加像素、美学、技术画质的独立provider契约及视图级观测身份；测试失败、缺失、真实零分、非法数值和模型版本变化，防止基础统计冒充美学评分。
- [ ] 4.2 接入选定美学与画质provider及可配置领域分类/人工覆盖，冻结权重与校准引用；以可追溯的模型适配运行及缺模型、未校准状态验证验收，不将适配成功解释为选样收益。
- [ ] 4.3 实现单一主路由、多原因记录和主集/辅助候选/复核/隔离目录；测试大文字与疑似水印共存、仅尺寸不足、不可解码及用途差异，原始资产不能被全局标坏。
- [ ] 4.4 增加策略dry-run影响预览，输出原因、领域、分数分布、未知项和重算范围；验证调整阈值只重做选择、更换模型重算相关观测，合成预期数量一致且旧版本未变。
- [ ] 4.5 补齐评分与分流手册及CLI/看板字段，说明原图与视图、分数与门槛、辅助候选与训练准入的区别；合成端到端运行展示各池数量可回溯至互斥主结果。

## 5. P4：短中长描述、最终条件与版本交付

对应[三档描述规格](specs/imagecaption-caption-variants/spec.md)、数据版本及质量分流规格。

- [ ] 5.1 纳管长描述生成及现有摘要工具，增加中/短变体的独立状态、模型模板与父标注引用；测试中描述失败只重做受影响分支，CLI和看板分别报告三档及全部所需变体合格图片数。
- [ ] 5.2 增加中短描述事实一致性审核及长描述视图审核接口；构造数量/关系冲突与新增事实夹具验证待复核，文本一致性通过不能代替长描述视觉审核。
- [ ] 5.3 建立视图级正常文字、水印等独立属性与caption绑定，处理裁剪和人工改判后的失效；测试原图与裁后属性差异及旧标注不可无证据复用。
- [ ] 5.4 实现选择变体后组装属性、目标模板和完整tokenizer长度检查，保存实际条件摘要；测试基础caption合格但拼接后超长、关键属性丢失及辅助适配器不消费字段时阻断。
- [ ] 5.5 实现固定短/中/长sidecar导出和显式混合模式适配入口；实际加载验证固定模式不复制三倍图片、不支持采样的加载器拒绝混合，支持的适配器记录权重、随机策略及缺失规则。
- [ ] 5.6 实现版本差异及内容复用，固定成员、视图、标注、审核和策略引用；验证只改caption生成新版本并复用图像，旧版本仍读到旧内容，比较输出明确变更原因。
- [ ] 5.7 完成发布状态、实际摘要/来源/必需标注校验及主辅关联组切分；测试原图/裁剪图跨划分、外部文件改写、必要复核未解决和中断后恢复，未选辅助候选不阻塞无关联主集。
- [ ] 5.8 编写三档生成、最终条件、版本比较及训练导出操作说明；使用合成资产和标注跑通可用版本的实际读取，记录所消费字段，区分适配验收与模型效果验证。

## 6. P5：全流程集成与受限试点

本组只验证跨组行为，不替代各组已有契约、集成测试和文档。

- [ ] 6.1 对CLI→事件→网页→版本发布执行合成全链路恢复演练，覆盖worker终止、重复事件、网络中断、迟到写入、checkpoint损坏和浏览器重连；证明计数不重复、输出可校验且旧版本可读。
- [ ] 6.2 在隔离环境演练旧数据库增量迁移、历史清单纳管和旧CLI/策略回滚；核对迁移前后已知资产及旧接口语义不变，缺失历史证据保持unknown，新流程不覆盖原产物。
- [ ] 6.3 用代表性合成规模验证事件/查询开销、分片checkpoint恢复、并发和看板刷新边界；报告环境、数据量、p95延迟及资源测量，不将单机合成结果推算为真实模型吞吐。
- [ ] 6.4 按用户允许范围开展只读结构试点并汇总版本和阶段计数；真实误检、裁剪主体保留、文字/美学门槛及caption质量由用户或授权审核者提供校准证据，未获证据项保持未验收，禁止查看或展示用户限制的图片与语义内容。
