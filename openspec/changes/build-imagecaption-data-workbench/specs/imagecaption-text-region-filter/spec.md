# Spec Delta

## Purpose

本能力对整幅图像及实际训练视图中的文字区域做独立检测和面积评价，将大范围文字覆盖作为主数据集的可配置过滤依据，避免依赖水印框内OCR而漏掉普通大段文字，并保留不确定结果和可审计证据。

## ADDED Requirements

### Requirement: 整图文字观测

系统 SHALL 检测整幅图像的文字区域，保存坐标空间、区域置信度、模型版本及输入摘要；文字检测不以水印框存在为前提，字符识别结果独立保存。

#### Scenario: 没有水印框但存在大段文字
- **WHEN** 水印检测未产生候选而整图文字检测有可信大文字区域
- **THEN** 仍执行文字面积策略，不直接通过主集过滤。

### Requirement: 面积与文字块定义

系统 SHALL 记录裁边和去重后文字区域的并集面积占比，以及按固定局部分组规则形成的最大文字块占比；不得累加重叠框面积或用所有文字的全局外接矩形替代文字并集。

#### Scenario: 重复框和分散文字
- **WHEN** 同一区域有重叠候选且另有距离较远的文字
- **THEN** 重叠只计一次，远处空白不被全局外接框计为文字，并能追溯分组参数。

### Requirement: 阈值校准与主集过滤

系统 SHALL 将置信度、最大块和并集占比门槛固化在领域策略中；阈值未校准时只输出统计和待校准状态，确认超阈值时从主集排除并保留原因及原始资产。

#### Scenario: 已确认大面积文字覆盖
- **WHEN** 校准后的检测与面积结果超过主集策略门槛
- **THEN** 样本不能进入主集，可按独立属性用途评估，不自动标成水印负样本。

### Requirement: 未知与失败不等于无文字

系统 SHALL 区分正常无文字、低可靠性、执行失败和不支持；可疑全图框或其他异常几何须进入复核，失败结果不能按零占比通过。

#### Scenario: 文字检测服务超时
- **WHEN** 无法获得有效检测结果
- **THEN** 保存失败及重试状态，不能显示为已确认无文字或已通过文字过滤。

### Requirement: 裁后视图复检

系统 SHALL 在实际裁剪视图上重算或重新检测文字区域，并记录使用的变换与复核方式；原图准入不自动证明裁后准入。

#### Scenario: 裁剪使文字覆盖比例增大
- **WHEN** 原图的文字占比合格但裁后占比超阈值
- **THEN** 拒绝该视图进入主集，并保留原图及裁后两个观测版本。
