# Spec Delta

## Purpose

本能力负责图像完整性与基础观测，为图像训练数据全流程提供独立、可追溯且可验证的行为契约，明确输入处理、失败结果和下游使用边界，支持后续分阶段实现与验收。

## ADDED Requirements

### Requirement: 解码验证与独立结果

系统 SHALL 实际解码图像，记录损坏、格式、尺寸、位深、通道、帧数和解码限制，区分数据错误与执行失败。

#### Scenario: 解码服务暂时不可用
- **WHEN** 解码服务暂时不可用
- **THEN** 记录可重试任务失败，不将图像判为损坏。

### Requirement: 方向和通道语义

系统 SHALL 记录 EXIF 方向与色彩空间，并对透明、动画、高位深文件给出明确处理结果。

#### Scenario: 输入含 alpha 的图像
- **WHEN** 输入含 alpha 的图像
- **THEN** 保留原始 alpha；派生背景合成必须记录背景与变换策略。

### Requirement: 观测与筛选分离

系统 SHALL 版本化记录熵、压缩、模糊、尺寸等观测，避免将单个指标直接变为全局拒收状态。

#### Scenario: 模糊图片用于动感摄影配方
- **WHEN** 模糊图片用于动感摄影配方
- **THEN** 可由该配方接受，即使其他配方拒收。
