# Spec Delta

## Purpose

本能力负责任务化标注与字段审核，为图像训练数据全流程提供独立、可追溯且可验证的行为契约，明确输入处理、失败结果和下游使用边界，支持后续分阶段实现与验收。

## ADDED Requirements

### Requirement: 多类型多版本标注

系统 SHALL 独立保存短中长描述、文字、布局、风格与知识信息，记录对应图像视图、模型、提示模板和推理参数版本。

#### Scenario: 同图生成通用与文字专项标注
- **WHEN** 同图生成通用与文字专项标注
- **THEN** 两套结果独立可查，文字原文不被描述改写覆盖。

### Requirement: 知识与可见证据

系统 SHALL 将视觉可见信息与外部知识区分，知识字段必须保留证据来源与审核状态。

#### Scenario: 模型猜测无法验证的实体身份
- **WHEN** 模型猜测无法验证的实体身份
- **THEN** 标为未验证知识，不作为已确认事实导出。

### Requirement: 字段级审核与复审

系统 SHALL 分别审核格式、拒答、重复、幻觉、OCR和关系；支持字段重做、人工裁决及审核器版本追踪。

#### Scenario: OCR 不可靠但主体描述可信
- **WHEN** OCR 不可靠但主体描述可信
- **THEN** 文字用途待复审或拒收，通用描述仍可按配方使用。

### Requirement: 长度与语言兼容

系统 SHALL 按目标 tokenizer 计算长度并记录截断策略，对短中长改写检查语义一致性。

#### Scenario: 长描述超过目标模型长度且关键文字在尾部
- **WHEN** 长描述超过目标模型长度且关键文字在尾部
- **THEN** 阻止静默截断，通过重写或拒收生成明确结果。
