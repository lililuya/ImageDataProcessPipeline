# Spec Delta

## Purpose

本能力负责分层重复治理与泄漏防护，为图像训练数据全流程提供独立、可追溯且可验证的行为契约，明确输入处理、失败结果和下游使用边界，支持后续分阶段实现与验收。

## ADDED Requirements

### Requirement: 分层检测可追溯

系统 SHALL 区分字节相同、感知相近和语义相近，保存算法版本、候选、相似度和簇成员；语义相近不得自动等同可删除。

#### Scenario: 同一商品两个拍摄角度被召回
- **WHEN** 同一商品两个拍摄角度被召回
- **THEN** 产生候选并按任务策略判定，不直接删除第二张。

### Requirement: 代表样本选择

系统 SHALL 按配方选择重复簇代表，保留全部资产和决策理由。

#### Scenario: 两个近重复图的质量与来源许可不同
- **WHEN** 两个近重复图的质量与来源许可不同
- **THEN** 选择满足许可和质量策略的代表，记录另一张未选原因。

### Requirement: 关联组划分

系统 SHALL 将已知重复簇、派生亲缘与任务关联组纳入划分连通分量，并检查训练与评测跨集合污染。

#### Scenario: 两个重复簇通过编辑源图建立关联
- **WHEN** 两个重复簇通过编辑源图建立关联
- **THEN** 整个关联分量只分到一个集合；后续发现跨集合关联时阻止受影响的新发布。
