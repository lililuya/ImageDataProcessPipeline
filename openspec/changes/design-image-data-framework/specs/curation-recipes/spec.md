# Spec Delta

## Purpose

本能力负责阶段配方与覆盖控制，为图像训练数据全流程提供独立、可追溯且可验证的行为契约，明确输入处理、失败结果和下游使用边界，支持后续分阶段实现与验收。

## ADDED Requirements

### Requirement: 不可变配方与可解释决策

系统 SHALL 对筛选、字段依赖、阈值、审核、采样、模型适配与随机种子生成配方摘要，决策必须引用观测版本。

#### Scenario: 质量模型升级但旧发布需要复查
- **WHEN** 质量模型升级但旧发布需要复查
- **THEN** 仍能找到旧观测和决策，新结果使用新配方或观测引用。

### Requirement: 领域与阶段策略

系统 SHALL 支持按领域、任务和分辨率配置阈值及课程，所有论文阈值默认为未校准参考值。

#### Scenario: 低分辨率课程不接受文字过密图
- **WHEN** 低分辨率课程不接受文字过密图
- **THEN** 仅该课程排除，图像仍能进入高分辨率文字课程。

### Requirement: 长尾与采样审计

系统 SHALL 报告筛选前后概念覆盖、来源集中度、领域和风格分布、唯一资产数与预期样本次。

#### Scenario: 热门簇挤占长尾概念配额
- **WHEN** 热门簇挤占长尾概念配额
- **THEN** 输出配额偏差；不可满足配额必须显式失败或记录批准的降级策略。

### Requirement: 合成比例与caption策略

系统 SHALL 单独配置真实/合成/未知配比、短中长 caption 权重与风格触发词策略。

#### Scenario: 执行风格 LoRA 配方
- **WHEN** 执行风格 LoRA 配方
- **THEN** 仅导出变体省略指定风格信息，完整基础标注仍保留。
