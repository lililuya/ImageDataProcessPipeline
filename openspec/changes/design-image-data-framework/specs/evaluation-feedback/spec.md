# Spec Delta

## Purpose

本能力负责审计评测与补数闭环，为图像训练数据全流程提供独立、可追溯且可验证的行为契约，明确输入处理、失败结果和下游使用边界，支持后续分阶段实现与验收。

## ADDED Requirements

### Requirement: 分层人工审核

系统 SHALL 按来源、领域、分数区间、拒收原因与边界样本抽样，记录抽样概率、人工标签和置信区间。

#### Scenario: 评估筛选器误删率
- **WHEN** 评估筛选器误删率
- **THEN** 报告抽样口径、分层结果和加权汇总，不将定向抽样均值冒充总体比例。

### Requirement: 数据与模型分开评价

系统 SHALL 同时记录数据质量、工程成本和固定模型评测，模型对照固定预算、基线、提示与种子。

#### Scenario: 更换筛选器后比较两个训练结果
- **WHEN** 更换筛选器后比较两个训练结果
- **THEN** 报告训练预算、唯一样本数和样本次差异，限制因果结论。

### Requirement: 错误归因与受控补数

系统 SHALL 将生成错误关联到能力标签、数据缺口、补数工单和对照发布，锁定最终测试集。

#### Scenario: 文字渲染评测暴露中文小字短板
- **WHEN** 文字渲染评测暴露中文小字短板
- **THEN** 创建对应补数计划，在开发集迭代并对新发布回归，不能将测试图或其近重复补入训练。

### Requirement: 可观测与脱敏

系统 SHALL 提供各关数量漏斗、队列积压、重试、吞吐、成本和版本指标，默认日志不含原图、凭据与完整敏感文字。

#### Scenario: 标注 API 持续失败
- **WHEN** 标注 API 持续失败
- **THEN** 能定位算子版本和错误类别，日志不泄露请求凭据。
