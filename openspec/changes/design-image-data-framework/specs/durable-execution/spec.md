# Spec Delta

## Purpose

本能力负责持久处理与资源调度，为图像训练数据全流程提供独立、可追溯且可验证的行为契约，明确输入处理、失败结果和下游使用边界，支持后续分阶段实现与验收。

## ADDED Requirements

### Requirement: 幂等结果与版本失效

系统 SHALL 用输入摘要、算子版本、模型摘要及配置摘要确定任务身份，完整提交结果后才解锁下游。

#### Scenario: 任务在上传产物后、提交结果前崩溃
- **WHEN** 任务在上传产物后、提交结果前崩溃
- **THEN** 重试能复用或校验产物，仅一个结果成为有效结果；孤儿对象不进入发布。

### Requirement: 租约与过期提交

系统 SHALL 使用可续期租约、领取令牌和条件提交，拒绝已失去任务所有权的 worker 更新结果。

#### Scenario: 旧 worker 在租约过期并被重新领取后返回
- **WHEN** 旧 worker 在租约过期并被重新领取后返回
- **THEN** 拒绝旧提交且保留当前租约持有者结果。

### Requirement: 有限重试与人工恢复

系统 SHALL 按错误类型执行带退避的有限重试，耗尽后隔离并支持人工重放。

#### Scenario: 永久损坏输入反复失败
- **WHEN** 永久损坏输入反复失败
- **THEN** 任务进入隔离状态，原因可查，不持续消耗 GPU。

### Requirement: 资源与费用边界

系统 SHALL 声明 CPU/GPU/API 资源、并发、速率与预算，并支持停止新领取而安全完成在途任务。

#### Scenario: API 批次将超过预算
- **WHEN** API 批次将超过预算
- **THEN** 停止新增请求，保存进度与预算事件；已完成结果可复用。
