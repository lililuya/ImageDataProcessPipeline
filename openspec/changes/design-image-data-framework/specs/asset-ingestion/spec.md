# Spec Delta

## Purpose

本能力负责来源登记与资产管理，为图像训练数据全流程提供独立、可追溯且可验证的行为契约，明确输入处理、失败结果和下游使用边界，支持后续分阶段实现与验收。

## ADDED Requirements

### Requirement: 内容寻址与来源独立

系统 SHALL 用原始字节 SHA-256 标识资产，并独立保存来源、批次、原始标识、获取时间和授权状态。

#### Scenario: 同一文件通过两个来源重复接入
- **WHEN** 同一文件通过两个来源重复接入
- **THEN** 仅创建一个资产，保留两个来源关系；同一批次重放不重复创建来源记录。

### Requirement: 原始数据不可覆盖

系统 SHALL 保留原始文件与校验值，派生操作不得覆盖原始资产。

#### Scenario: 方向纠正或重编码完成
- **WHEN** 方向纠正或重编码完成
- **THEN** 原始字节校验值不变，新文件作为派生产物登记。

### Requirement: 来源可用性与访问控制

系统 SHALL 限制原始数据访问，记录访问主体；未满足发布用途授权策略或已撤回的来源不得支持新发布。

#### Scenario: 资产唯一可用来源撤回授权
- **WHEN** 资产唯一可用来源撤回授权
- **THEN** 新发布排除该资产，生成受影响历史发布清单，不静默修改历史清单。
