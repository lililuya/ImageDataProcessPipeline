# Spec Delta

## Purpose

本能力负责训练任务与关联样本，为图像训练数据全流程提供独立、可追溯且可验证的行为契约，明确输入处理、失败结果和下游使用边界，支持后续分阶段实现与验收。

## ADDED Requirements

### Requirement: 任务模式与角色

系统 SHALL 区分 image-only、T2I、文字、编辑、多参考、透明、风格与偏好任务，并校验各任务必需字段。

#### Scenario: 为多参考编辑提供三张输入
- **WHEN** 为多参考编辑提供三张输入
- **THEN** 保存有序输入、各自角色及目标，不合并为无序文件列表。

### Requirement: 编辑正确性

系统 SHALL 审核源到目标变化方向、指令可执行性、保留区域和身份一致性。

#### Scenario: 指令要求红变蓝但源图为蓝目标为红
- **WHEN** 指令要求红变蓝但源图为蓝目标为红
- **THEN** 拒收或重写后重新审核，不能直接作为正确编辑发布。

### Requirement: 模型能力适配

系统 SHALL 在导出前验证任务与目标模型及加载器的能力兼容性。

#### Scenario: 普通 T2I 加载器收到 image-only 自条件配方
- **WHEN** 普通 T2I 加载器收到 image-only 自条件配方
- **THEN** 明确拒绝，不能通过空 caption 静默模拟该训练方法。

### Requirement: 合成与偏好谱系

系统 SHALL 记录真实/合成/未知来源标记；合成样本记录生成器与参数，偏好对记录相同条件、候选顺序和裁决依据。

#### Scenario: 偏好对的两个候选使用不同参考图
- **WHEN** 偏好对的两个候选使用不同参考图
- **THEN** 标记条件不一致并阻止偏好训练导出。
