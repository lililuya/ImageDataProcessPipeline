# Spec Delta

## Purpose

本能力负责训练视图与监督一致性，为图像训练数据全流程提供独立、可追溯且可验证的行为契约，明确输入处理、失败结果和下游使用边界，支持后续分阶段实现与验收。

## ADDED Requirements

### Requirement: 可复现变换

系统 SHALL 保存目标 bucket、裁剪框、缩放、插值、方向、随机种子和算子版本，并记录有效分辨率与放大比例。

#### Scenario: 重新构建相同固定视图
- **WHEN** 重新构建相同固定视图
- **THEN** 在固定解码环境内输出相同校验值；环境变化产生新视图版本。

### Requirement: 监督与画面匹配

系统 SHALL 确认实际训练视图与 caption、OCR、参考条件一致；裁剪掉监督对象时重标、换视图或拒绝该样本。

#### Scenario: 裁剪移除了 caption 描述的第二个人
- **WHEN** 裁剪移除了 caption 描述的第二个人
- **THEN** 原 caption 不能直接随裁剪图发布。

### Requirement: 训练端随机变换约束

系统 SHALL 在运行时增强时绑定可重放变换策略，并限制其不破坏已审核的监督。

#### Scenario: 训练端请求随机裁剪文字密集海报
- **WHEN** 训练端请求随机裁剪文字密集海报
- **THEN** 仅允许配方声明并验证的增强；否则拒绝该增强配置。

### Requirement: 透明图像质量

系统 SHALL 对透明任务检查 alpha 与前景边缘，预览使用可识别透明背景，普通 RGB 转换需独立派生。

#### Scenario: 透明前景边缘存在明显杂色
- **WHEN** 透明前景边缘存在明显杂色
- **THEN** 记录边缘问题并进入专项审核，不将白底预览误认为原始图。
