# Tasks

以下为 apply 的实施任务，勾选项已有验证证据，未勾选项仍待完成。每组随实现交付对应测试与操作说明；M0–M4 是交付顺序，不是虚构工期。规格路径均在本 change 的 specs/ 下。

## 1. M0 数据契约与基准

- [x] 1.1 实现公共 envelope、资产、来源、视图 schema；通过重复来源、非法摘要及字段缺失契约测试，对应 asset-ingestion。
- [x] 1.2 实现八类任务样本 schema 与能力声明；通过多参考顺序、偏好条件不一致及 image-only 不兼容测试，对应 task-datasets。
- [x] 1.3 建立合成夹具：损坏、EXIF旋转、RGBA、多帧、小字、重复、编辑反向；夹具说明列出预期结论并验证无真实用户数据。
- [x] 1.4 实现分层审计抽样清单；输出入样概率、人工标注模板与加权估计示例，通过定向过采样恢复总体比例测试。
- [ ] 1.5 填写本机/生产资源及成本配置，执行小样本 CPU/GPU/API 基准并生成容量报告；无 GPU 时明确标记未测项，不使用模拟值冒充实测。
